### Evidence behind the projects

LOGFLUX's committed reports document a **900,000-event broker/evidence acceptance run at 15,000 events/s for 60 seconds**, plus full-file dry-run validation across **40,316,437 public event records**. These are project-level results from the documented configurations; corpus coverage does not imply detection accuracy. See the [verification index](https://github.com/Sachin-MS-77/LOGGER/blob/HEAD/docs/VERIFICATION.md).

PARALLAX separates triage priority from criminality and labels network observations without inferring wallet ownership. Its demonstration evaluation uses synthetic data. Impact remains a local prototype whose published evaluation does not meet its production adoption gates.
